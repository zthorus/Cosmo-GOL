# Cosmo-GOL
Conway's Game of Life for the ZX Spectrum

A classical version of Conway's Game of Life for the Sinclair ZX Spectrum. The main loop of the algorithm has been coded in Z80 assembly language, using the Mekias assembler. The code in assembly language is stored in REM lines of the Basic program. The Mekias assenmbler is already installed in the RAM image files (.z80 and .sna). Type RUN, wait a few seconds for the beep (meaning that compilation is OK) and type ENTER. The Basic program provides, as examples, two well-known figures: the glider (line 1050) and the blooming (line 1060). they can be activated/disabled by deleting/inserting the REM command in those lines..
